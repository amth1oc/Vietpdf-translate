## 2. Thuật ngữ chuyên ngành (5 lớp)

| Lớp | Cách làm | Lệnh / tuỳ chọn |
| --- | --- | --- |
| Kho 3 tầng | chuyên ngành đóng gói (CNTT–AI, Toán–Thống kê, Kinh tế, Sinh–Y, Vật lý–Hoá, Pháp lý) < của tài liệu < của người dùng | `--glossary file.csv`, `~/.config/vietpdf/glossary/*.csv` |
| Nhận diện lĩnh vực + tóm tắt | 1 request, cache; quyết định glossary nạp và làm ngữ cảnh mọi lô | `--domain` để tự chọn, `--no-domain` để tắt |
| Trích thuật ngữ | trên máy: n-gram lặp, viết tắt "Long Form (LF)", chữ đậm/nghiêng, cụm định nghĩa; LLM chỉ đề xuất cho ứng viên chưa có (kết quả lạ bị loại) | `vietpdf terms file.pdf -o tn.csv` để duyệt; GUI: màn duyệt thuật ngữ |
| Ép thuật ngữ | thường: bảng "BẮT BUỘC" chỉ gồm thuật ngữ có trong lô; nghiêm ngặt: thay bằng ⟦T⟧ rồi điền bản chuẩn | `--strict-terms` (mặc định với Ollama) |
| Kèm gốc lần đầu | "học máy (machine learning)" chỉ ở lần xuất hiện đầu toàn tài liệu | tắt: `--no-first-mention` |
| Kiểm tra sau dịch | thiếu bản chuẩn ⇒ dịch lại 1 lần kèm nhắc ⇒ vẫn thiếu: cờ `term:missing` | báo cáo nhất quán trong `*.report.md` |
| Học từ chỉnh sửa | GUI: ô "Học từ chỉnh sửa" khi sửa đoạn ⇒ lưu vào glossary của tôi | |

## 3. Dịch theo nghĩa

- Đơn vị dịch là cả đoạn (đã nối dòng, nối qua cột/trang), kèm tiêu đề, tóm tắt, lĩnh vực, đoạn liền trước.
- Prompt có ví dụ "sát chữ / đúng ý"; văn phong `de_doc` (mặc định), `sat_nghia`, `hanh_chinh`.
- Kiểm tra trên máy: số liệu, phủ định, chiều tăng/giảm, độ dài bất thường.
- **Biên tập lượt 2**: `--quality fast` (1 lượt) · `standard` (chỉ đoạn bị nghi) · `high` (mọi đoạn, ~2× token).
  `--editor-provider/--editor-model` để biên tập bằng mô hình khác (bị chặn nếu đang offline nghiêm ngặt mà chọn dịch vụ đám mây).
- **Giải thích tách khỏi bản dịch**: ghi chú nổi trong PDF (`--annotate-terms`) và phụ lục chú giải (`--glossary-appendix`), luôn ghi nhãn "Giải thích của AI" hoặc "Theo bảng thuật ngữ".

## 4. Ứng dụng hoàn chỉnh

| Tính năng | CLI | GUI |
| --- | --- | --- |
| Hàng đợi nhiều file, kéo-thả | (lặp lệnh) | Tab **Dịch** |
| Chọn trang, dừng/tiếp | `--pages`, Ctrl+C rồi chạy lại | ô Trang, nút Dừng |

| Xem song song, cuộn/phóng đồng bộ, rê chuột tô đoạn tương ứng | — | Tab **Xem & sửa** |
| Sửa tay rồi xuất lại không gọi API | sửa `*.ir.json` + `vietpdf render` | nhấp đúp đoạn → "Xuất lại PDF" |
| Quản lý glossary, nhập/xuất CSV | `--glossary` | Tab **Thuật ngữ** |
| Lịch sử, xoá cache | `vietpdf cache info/clear` | Tab **Lịch sử** |
| Giao diện Việt/Anh, sáng/tối | — | góc phải thanh công cụ (nhãn chính) |

## 5. Báo cáo sau mỗi file

`ten-file.report.md` (+ `.report.json`): số đoạn, lĩnh vực, trang OCR, tóm tắt, **bảng đoạn cần xem lại** (cờ
`qa:*`, `term:missing`, `overflow`, `security:injection-like`) và **bảng thuật ngữ chưa nhất quán**.
